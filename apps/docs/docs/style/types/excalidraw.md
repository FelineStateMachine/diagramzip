# Style Excalidraw

Excalidraw stores the style of each element in the JSON source.

Start with the [general presentation settings](/style/presentation). Edit shared or raw presentation in Details, and keep renderer-specific styling in Source.

## Source controls

- Use the Excalidraw editor to change element styles safely.
- Element values include stroke, fill, roughness, opacity, and font properties.
- The application state can define the source canvas color.
