# Style Diagrams.net

Diagrams.net stores geometry and style values on cells in the XML source.

Start with the [general presentation settings](/style/presentation). Edit shared or raw presentation in Details, and keep renderer-specific styling in Source.

## Source controls

- Use the diagrams.net editor to change cell styles safely.
- The `style` attribute contains semicolon-separated cell settings.
- The geometry element contains the position and size.
