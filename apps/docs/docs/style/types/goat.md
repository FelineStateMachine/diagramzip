# Style GoAT

GoAT takes most geometry from the text. Renderer options control SVG colors and character handling.

Start with the [general presentation settings](/style/presentation). Edit shared or raw presentation in Details, and keep renderer-specific styling in Source.

## Source controls

- Change the text geometry to change placement.
- Use supported line and corner characters for the required shape.
- Use labels inside or near the related shape.

## Renderer options

| Option | Values | Purpose |
| --- | --- | --- |
| `svg-color-dark-scheme` | CSS color; default is `#FFF` | Set the foreground color for a dark color scheme. |
| `svg-color-light-scheme` | CSS color; default is `#000` | Set the foreground color for a light color scheme. |
| `utf8` | Flag | Treat Unicode box characters as the drawing characters. |
