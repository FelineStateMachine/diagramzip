# Style DBML

DBML describes schema structure. It does not define visual presentation.

Start with the [general presentation settings](/style/presentation). Edit shared or raw presentation in Details, and keep renderer-specific styling in Source.

## Source controls

- Use notes and labels to improve the rendered meaning.
- Use table groups to express related tables when the syntax version supports them.
- Use general presentation settings for the outer canvas.
