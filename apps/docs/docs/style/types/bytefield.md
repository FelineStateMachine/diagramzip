# Style Bytefield

Bytefield uses drawing-form properties for spans, labels, and layout.

Start with the [general presentation settings](/style/presentation). Choose a shared appearance, or use the renderer defaults with custom canvas controls.

## Source controls

- Use property maps on drawing forms.
- Use custom drawing forms only when the renderer supports them.
- Keep labels short when a field has a small span.
## Limitations

- diagram.zip returns SVG for this type.
