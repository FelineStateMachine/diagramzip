# Style ActDiag

ActDiag supports lane, action, edge, and diagram attributes.

Start with the [general presentation settings](/style/presentation). Choose a shared appearance, or use the renderer defaults with custom canvas controls.

## Source controls

- Set labels and colors on actions.
- Set lane labels and colors in lane blocks.
- Set edge labels and colors in edge attributes.

## Renderer options

| Option | Values | Purpose |
| --- | --- | --- |
| `antialias` | Flag | Apply the anti-alias filter. |
| `size` | `widthxheight` | Set the image size. |
| `no-doctype` | Flag | Remove the document type declaration from SVG output. |
