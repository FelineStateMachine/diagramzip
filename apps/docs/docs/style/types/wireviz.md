# Style WireViz

WireViz uses YAML properties for connector, cable, wire, and output styles.

Start with the [general presentation settings](/style/presentation). Choose a shared appearance, or use the renderer defaults with custom canvas controls.

## Source controls

- Set connector and cable colors in their YAML definitions.
- Use pin labels and wire colors to improve identification.
- Use WireViz metadata and output settings only when the renderer supports them.
