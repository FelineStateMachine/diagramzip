# Create and control a diagram.

Diagram.zip is a browser-based diagram editor. Write or paste source, edit structured details, inspect the result, then save or share it.

## Find a topic

- **Create**: choose a diagram type, edit Source and Details, and learn its short syntax guide.
- **Style**: set common presentation options in Details, then use type-specific settings.
- **Share**: understand read links, edit links, encryption, and saved state.

The pages use short examples and direct links. Agents can use the same stable URLs and code blocks.
