# Style WaveDrom

WaveDrom supports source configuration, signal attributes, and a limited set of bundled skins.

Start with the [general presentation settings](/style/presentation). They control the canvas background, padding, and frame for every diagram.

## Source controls

- Use the `config` object for scale and header settings.
- Use signal attributes for labels and wave data.
- Select only a skin that diagram.zip provides.
## Limitations

- Only the six bundled diagram.zip skins are available.
- diagram.zip returns SVG for this type.
