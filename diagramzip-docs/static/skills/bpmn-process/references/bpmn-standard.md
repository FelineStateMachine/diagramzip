# BPMN standard

BPMN 2.0.2 defines the notation, metamodel, and interchange concepts for business-process diagrams. ISO 19510 adopts the BPMN specification. Use the specification's distinction between sequence flow, message flow, events, activities, gateways, pools, and lanes when producing a formal model.

References: [OMG BPMN 2.0.2](https://www.omg.org/spec/BPMN/2.0.2/) and [ISO 19510](https://www.iso.org/standard/62652.html).

Rendering BPMN XML is not the same as validating or executing it. Treat validator, conformance profiles, and vendor-extension handling as explicit integration opportunities.
