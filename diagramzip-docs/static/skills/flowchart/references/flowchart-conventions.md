# Flowchart conventions

ISO 5807:1985, confirmed current in 2019, defines documentation symbols and conventions for data, program, and system flowcharts. Use it as a vocabulary and review aid rather than assuming that a renderer's shape names prove conformance.

Reference: [ISO 5807:1985](https://www.iso.org/standard/11955.html).

The standard is not bundled as executable validation in diagram.zip. Treat strict conformance checking as a possible future integration.
