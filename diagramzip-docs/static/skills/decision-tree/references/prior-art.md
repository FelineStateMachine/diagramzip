# Decision-tree references

- [OMG DMN 1.5](https://www.omg.org/spec/DMN/1.5/) — latest formal prior art for decision requirements, decision logic, and FEEL; not a native diagram.zip renderer.
- [Mermaid flowchart syntax](https://mermaid.js.org/syntax/flowchart.html) — supported renderer for readable informal decision trees.
- [ISO 5807:1985](https://www.iso.org/standard/11955.html) — flowchart symbol convention relevant to decision/process notation.

DMN support would require XML parsing, decision requirements notation, and likely FEEL-aware validation. Do not imply that a Mermaid diamond is DMN-conformant.
