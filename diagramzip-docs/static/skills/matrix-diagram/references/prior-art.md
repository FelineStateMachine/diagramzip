# Matrix references

- [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/) — accessibility requirements for non-text contrast, use of color, and text alternatives.
- [Vega-Lite documentation](https://vega.github.io/vega-lite/) — supported declarative data-visualization renderer for quantitative matrices and heatmaps.
- [RACI model](https://www.pmi.org/learning/library/responsible-accountable-consulted-informed-raci-roles-7382) — established prior art for responsibility matrices.

diagram.zip does not currently expose a matrix schema, automatic color-scale validator, or ARIA/table alternative generator. Those are concrete integration opportunities if matrices become a first-class semantic type.
