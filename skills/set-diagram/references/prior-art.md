# Set-diagram references

- [Euler diagram definition (Encyclopaedia of Mathematics)](https://encyclopediaofmath.org/wiki/Euler_diagram) — prior art distinguishing diagrams that show only existing set intersections.
- [Venn’s original set diagram paper](https://doi.org/10.1080/14786440508637087) — historical prior art for systematic set intersections.
- [W3C SVG accessibility guidance](https://www.w3.org/TR/SVG-access/) — relevant when a set diagram is delivered as SVG and needs meaningful text alternatives.

No supported diagram.zip renderer currently guarantees a valid Venn or Euler layout from arbitrary set membership data. Treat overlap geometry as illustrative unless an integration adds validation.
