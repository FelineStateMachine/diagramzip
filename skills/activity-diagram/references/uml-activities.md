# UML activities

UML 2.5.1 defines activities, actions, control nodes, object nodes, flows, and activity partitions (often rendered as swimlanes). Use the formal concepts when the workflow is a software or systems design artifact.

Reference: [OMG UML 2.5.1](https://www.omg.org/spec/UML/2.5.1).

Generic flowchart renderers can display the picture but do not validate UML activity semantics. Strict validation remains an integration opportunity.
